# Python Scientific Calculator

This project is a scientific calculator developed using Python.

The calculator can perform mathematical calculations, solve equations, plot graphs and store calculation history. It also includes a user account system using SQLite.

---

## How It Works

When the program starts, the user can create an account or log in.

Once logged in, the user can choose between different calculator functions.

The calculator supports:

- **Scientific Calculations** – Addition, subtraction, multiplication, division, powers, trigonometry, logarithms and factorials.
- **Complex Numbers** – Calculations involving real and imaginary numbers.
- **Polynomial Solver** – Solves quadratic equations, including complex solutions.
- **Simultaneous Equation Solver** – Solves two linear equations.
- **Graph Plotting** – Plots mathematical functions using Matplotlib.
- **Calculation History** – Saves previous calculations for each user.
- **Angle Units** – Switches between degrees and radians.

---

## User Account System

The program uses an SQLite database to store user accounts.

Users can create an account with a username and password.

The system includes password requirements and temporarily locks accounts for 5 minutes after three incorrect password attempts.

Each account has its own calculation history, which can be viewed or cleared.
